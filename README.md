# mos-6502

The MOS 6502 CPU, cycle-stepped, with a pin-level bus interface.

| Crate | Registry |
|---|---|
| [`emu198x-mos-6502`](crates/emu198x-mos-6502) | [crates.io](https://crates.io/crates/emu198x-mos-6502) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by its Commodore, Atari, Acorn, Nintendo and Oric machines, and by Play198x for `.sid` playback.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
